  - `수업신청` 시트: 1행에 `이름 | 이메일 | 관심 분야 | 신청 시각`

1. **설명 10분 넘기지 않기.** 설명 → 바로 노드 놓기 → OUTPUT 같이 보기
2. 블록마다 **"체크포인트"**. 통과한 사람은 손 들기 / 채팅에 ✅

5. 막히면 **OUTPUT 화면을 같이 보기.** "몇 items 라고 써 있어요?" 가 최고의 질문

### 📢 오늘의 규칙 (학생에게 첫 화면으로)
- 노드 하나 놓을 때마다 **Execute step**
- 노드 이름은 **하는 일**로 바꾸기 (`Edit Fields1` 금지)

## 블록 1. 첫 워크플로우 + 데이터 모양 (40분) — 교재 2~3단계

### 목표
**트리거 → 노드 → Execute step → OUTPUT 확인** 리듬 익히기 + item 감각

### 1-1. 첫 블록 두 개 (10분)
1. **Create workflow** → 왼쪽 위 제목을 `01-연습` 으로
2. **+ (Add first step)** → **Trigger manually**
3. 트리거 오른쪽 **+** → `Edit Fields` 검색 → **Edit Fields (Set)**
4. **Add Field** → `message` / String / `안녕 n8n!`
5. **Execute step** → 오른쪽 OUTPUT 확인
6. 노드 이름 바꾸기: 노드 선택 → **F2** (또는 설정창 위 제목 클릭) → `인사말 만들기`
7. 캔버스 아래 **Execute workflow** → 초록 체크 ✅

### 1-2. 학생 명단 다루기 (15분)
`인사말 만들기` 노드를 열어 **Mode → JSON** 으로 바꾸고 붙여넣기:
```json
{ "students": [
  { "name": "홍길동", "score": 85, "track": "AI" },
  { "name": "김철수", "score": 62, "track": "웹" },
  { "name": "이영희", "score": 93, "track": "AI" },
  { "name": "박민수", "score": 77, "track": "앱" }
] }
```
→ 이름을 `명단 불러오기` 로 바꾸고 Execute step → OUTPUT 을 **Schema / Table / JSON** 으로 바꿔보기
→ 위에 **"1 item"** 이라고 써 있는 걸 같이 확인

다음 노드 **Split Out** → Fields To Split Out: `students` → 이름 `한 명씩 나누기` → Execute step → **"4 items"** ✅

### 1-3. 🎮 item 개수 맞히기 게임 (10분)
강사가 노드를 하나씩 추가하며 **실행 전에** 묻습니다. "OUTPUT 은 몇 items 일까요?"

| 다음에 붙일 노드 | 설정 | 정답 |
|---|---|---|
| Filter | `score` ≥ 80 (Number) | 2 |
| Sort | `score` Descending | 2 (순서만 바뀜) |
| Limit | Max Items 1 | 1 |
| Aggregate | Individual Fields: `name` | 1 (안에 이름 목록) |

→ 맞힌 사람 손 들기. **item 개수를 예측하는 능력 = n8n 실력**

### 1-4. 정리 (5분)
Filter 이후 노드들 삭제 (노드 선택 → Delete). `한 명씩 나누기` 까지만 남기기 → 다음 블록에서 이어서

### ✅ 체크포인트
- [ ] `한 명씩 나누기` OUTPUT 이 **4 items**
- [ ] 노드 이름이 하는 일로 바뀌어 있다
- [ ] Schema / Table / JSON 보기를 바꿀 수 있다

⭐ 보너스: Aggregate 결과를 다시 Split Out 으로 쪼개서 원래대로 돌려놓기
🆘 따라잡기: JSON 붙여넣기에서 에러 → 강사 채팅방의 JSON 을 **전체 선택 복사**해서 다시 (중괄호 하나만 빠져도 에러)

## 블록 2. 표현식 + 갈림길 (30분) — 교재 4~6단계

### 목표
`{{ }}` 로 사람마다 다른 문장 만들기 + If 로 나누기

### 2-1. 빈칸 공식 (12분)
`한 명씩 나누기` 다음 **Edit Fields** → 이름 `문장 만들기` → Add Field 3개:
| 이름 | 값 (Expression) |
|---|---|
| `greeting` | `{{ $json.name }}님, 점수는 {{ $json.score }}점입니다` |
| `result` | `{{ $json.score >= 80 ? '합격' : '재시험' }}` |
| `checked_at` | `{{ $now.toFormat('yyyy-MM-dd HH:mm') }}` |

- 처음 하나는 **직접 타이핑**, 나머지는 왼쪽 INPUT 의 필드를 **끌어다 놓기**
- 칸 아래 **미리보기**에 결과가 바로 보이는지 확인
- Execute step → Table 보기에서 4명 각자 다른 문장 ✅

💬 **질문 던지기**: "칸이 Fixed 인 상태에서 `{{ $json.name }}` 을 쓰면 어떻게 될까요?" → 직접 해보기 (글자 그대로 나옴)

### 2-2. 갈림길 (13분)
`한 명씩 나누기` 에서 **선을 하나 더** 뽑아 **If** 추가 → 이름 `80점 이상?`
- Conditions: `{{ $json.score }}` → **Number → is greater than or equal to** → `80`
- Execute step → **True Branch 2 / False Branch 2** 탭 확인
- true → Edit Fields `msg` = `🎉 {{ $json.name }} 합격`
- false → Edit Fields `msg` = `📚 {{ $json.name }} 재시험`
- 두 노드 → **Merge** (Mode: Append) → Execute workflow → 4 items 다시 모임

### 2-3. 마무리 (5분)
💬 **질문 던지기**: "If 대신 Switch 를 쓰면 `track` 별로 AI/웹/앱 세 갈래로 나눌 수 있어요. 언제 If, 언제 Switch?"

### ✅ 체크포인트
- [ ] 미리보기에서 표현식 결과를 확인했다
- [ ] If 의 True / False 출구에 각각 item 이 갔다

⭐ 보너스: **Switch** 로 `track` 이 AI / 웹 / 앱 인 경우 세 갈래로 나누기 (Mode: Rules)
🆘 따라잡기: 2-1 의 `greeting` 하나만 성공해도 OK → 2-2 로

## 블록 3. 🚀 자동화 ① 신청서 → 시트 → 메일 (50분) — 교재 7~8단계

### 목표
**첫 진짜 자동화.** 누가 폼을 제출하면 시트에 저장되고 그 사람에게 메일이 간다

```
[수업 신청 폼] → [신청 내용 정리] → [시트에 저장] → [확인 메일]
```

### 3-1. 폼 만들기 (10분)
1. **Create workflow** → `02-수업 신청` → **On form submission**
2. Form Title: `n8n 특강 신청` / Form Description: `신청하면 확인 메일이 갑니다`
3. **Add Form Element** 3개:
   - `이름` — Text — Required ✅
   - `이메일` — Email — Required ✅
   - `관심 분야` — Dropdown — Options: `AI`, `웹`, `앱` — Required ✅
4. **Execute step** → 아래 **Test URL** 폼이 새 탭으로 열림 → 내 정보로 제출 → OUTPUT 확인
5. 노드 이름 `수업 신청 폼`

### 3-2. 정리하기 (5분)
**Edit Fields** → 이름 `신청 내용 정리` → **Include Other Input Fields 끄기**
| 이름 | 값 |
|---|---|
| `이름` | `{{ $json['이름'] }}` |
| `이메일` | `{{ $json['이메일'] }}` |
| `관심 분야` | `{{ $json['관심 분야'] }}` |
| `신청 시각` | `{{ $now.toFormat('yyyy-MM-dd HH:mm') }}` |

> 한글이나 띄어쓰기가 있는 필드는 `$json['관심 분야']` 처럼 **대괄호 + 따옴표**

### 3-3. 시트에 저장 + 첫 열쇠 만들기 (15분)
1. **+** → `Google Sheets` → **Append row in sheet**
2. Credential: **Create new credential** → **Sign in with Google** → 개인 Gmail 선택 → 권한 **모두 허용** → 저장
3. Document: **From list** → 사본 만든 `수업신청` / Sheet: `시트1`
4. Mapping Column Mode: **Map Each Column Manually** → 각 열에 왼쪽 INPUT 필드를 끌어다 놓기
5. 이름 `시트에 저장` → Execute step → **구글 시트를 열어 새 줄 확인** ✅

### 3-4. 확인 메일 (10분)
1. **+** → `Gmail` → **Send a message**
2. Credential: **Create new credential** → Sign in with Google (시트와 **별도 열쇠**)
3. 설정:
   - To: `{{ $('신청 내용 정리').item.json['이메일'] }}`
   - Subject: `[n8n 특강] {{ $('신청 내용 정리').item.json['이름'] }}님 신청 완료`
   - Email Type: **Text**
   - Message:
```
{{ $('신청 내용 정리').item.json['이름'] }}님, 신청해주셔서 감사합니다.
관심 분야: {{ $('신청 내용 정리').item.json['관심 분야'] }}
신청 시각: {{ $('신청 내용 정리').item.json['신청 시각'] }}
```
   - Options → **Append n8n Attribution** 끄기 (메일 맨 아래 n8n 광고 문구 제거)
4. 이름 `확인 메일` → Execute step → **내 메일함 확인** ✅

## 블록 8. 🚀 나만의 자동화 — 2바퀴 (90분) — 교재 14단계

### 목표
**강사 없이**, 세 칸 설계도부터 Publish 까지 내 손으로. 1바퀴는 "따라 하기", 2바퀴는 **"내가 설계하기"** 입니다.

### 8-1. 고르기 + 설계 (15분)
작게 고를수록 끝까지 갑니다. (메뉴에 없는 것도 OK — 세 칸을 강사에게 먼저 보여주기)

| 난이도 | 자동화 | ① 언제 | ② 무엇을 | ③ 어디로 |
|---|---|---|---|---|
| ⭐ | 밤 10시 내일 할 일 리마인더 | Schedule | 요일별 문구 (Switch) | 텔레그램 |
| ⭐ | 환율 알림 | Schedule | HTTP (`https://api.frankfurter.dev/v1/latest?base=USD&symbols=KRW` → `rates.KRW`) | 텔레그램 |
| ⭐⭐ | 문의 폼 AI 분류 | Form | AI 가 환불/배송/기타 분류 → Switch | 시트 탭별 저장 + 급하면 텔레그램 |
| ⭐⭐ | 오늘의 공부 퀴즈 | Schedule | AI 가 주제별 퀴즈 1문제 생성 | 텔레그램 |
| ⭐⭐ | 텔레그램 메모봇 | Telegram Trigger | 메시지를 Data table 에 저장 | "저장했어요 ✅" 답장 |
| ⭐⭐⭐ | 텔레그램 AI 비서 | Telegram Trigger | AI Agent (+ Memory, 시트/Data table 도구) | 텔레그램 답장 |
| ⭐⭐⭐ | 내 앱과 연결 | Webhook (바이브 코딩한 앱에서 호출) | 데이터 정리 | 시트 저장 + 텔레그램 알림 |

종이(또는 메모장)에 세 칸을 적고 → **강사 확인** 받고 시작

### 8-2. 만들기 (60분)
규칙:
1. **노드 하나 → Execute step → OUTPUT 확인** (오늘의 리듬 그대로)
2. **n8n Assistant (Ctrl/Cmd + J)** 를 써도 됩니다. 단, AI 가 만든 노드는 **하나씩 열어서 무슨 일을 하는지 설명할 수 있어야** 합니다
3. 메시지·메일은 **나에게** 먼저
4. 완성되면 **⋯ → Settings → Error workflow** 에 `00-에러 알림` 연결

n8n Assistant 에게 이렇게 시작해도 됩니다 (교재 14단계):
```
① 언제: (내 설계)
② 무엇을: (내 설계)
③ 어디로: (내 설계)
조건: (있으면)
이 워크플로우를 만들어줘. 노드 이름은 한글로 하는 일을 적어줘.
```

### 8-3. 켜기 + 기록 (15분)
1. **Publish** (버전 이름: `v1 - 첫 운영`)
2. 실제 조건으로 한 번 돌려보기 (Schedule 은 잠깐 Minutes 로 → 확인 → 원래대로 → 다시 Publish)
3. **Download** 백업
4. 발표 메모: ① 세 칸 설계 ② 가장 오래 막힌 곳 ③ AI(Assistant)를 썼다면 어디를 직접 고쳤나

### 🧑‍🏫 강사 운영 팁
- 자리를 돌며 **"지금 어느 노드에서 몇 items 예요?"** 만 묻기. 마우스 잡지 않기
- 설계 3칸이 안 나오는 학생 → ⭐ 메뉴로 유도
- 시간 내 못 끝내도 OK — **어디서 멈췄는지 말할 수 있으면 성공**

### ✅ 체크포인트
- [ ] 세 칸 설계를 강사에게 확인받았다
- [ ] 내 자동화가 **Published** 상태다 (또는 멈춘 노드와 이유를 말할 수 있다)
- [ ] Error workflow 가 연결되어 있다

🆘 따라잡기: ⭐ 리마인더로 시작 → 블록 5 의 `03-아침 브리핑` 을 복제(⋯ → Duplicate)해서 HTTP·AI 노드를 빼고 문구만 바꾸면 15분 안에 완성

## 부록 B. 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| Google 연결 화면에서 "액세스 차단됨" | 회사·학교 계정 → **개인 Gmail** 로 다시 |
| Google Sheets 에 시트 목록이 안 보임 | 열쇠 만들 때 권한 체크를 해제함 → Credentials 에서 열쇠 삭제 후 다시 만들고 **모두 허용** |
| 시트에 빈 줄만 추가됨 | Mapping 에서 열에 값을 안 끌어다 놓음 / 시트 1행(헤더) 이름과 다름 |
| 메일에 `{{ ... }}` 가 그대로 | 칸이 **Fixed** → Expression 으로 |
| 메일이 스팸함으로 감 | 처음엔 정상. 스팸 아님 표시. 제목을 너무 광고처럼 쓰지 않기 |
| 텔레그램 `chat not found` | 봇에게 먼저 **시작** 누르고 메시지 보내기 / Chat ID 숫자 다시 확인 (그룹은 `-` 로 시작) |
| 텔레그램 `Unauthorized` | 봇 토큰 복사 실수 (앞뒤 공백) → 열쇠 다시 |
| Telegram Trigger 가 아무 반응 없음 | Execute step 을 누르고 **기다리는 상태**에서 메시지를 보내야 함 |
| Gemini `API key not valid` | 키 복사 실수 / aistudio 에서 새로 발급 |
| Gemini `429` / quota | 무료 한도 초과 → 1분 뒤 다시 / 다른 flash 모델 선택 |
| AI 가 시트를 안 찾아보고 대충 답함 | System Message 에 **도구 이름**을 정확히 적기 + 도구 노드 이름을 `FAQ 시트 검색` 으로 |
| 챗봇이 이전 대화를 기억 못 함 | **Simple Memory** 연결 확인 |
| 친구가 폼·채팅을 못 엶 | **Test URL** 을 줌 → Production URL / 공개 토글 + **Publish** |
| 수정했는데 반영 안 됨 | 버튼이 **Published, has changes** → 다시 Publish |
| Schedule 이 안 돎 | Publish 안 함 / Settings 의 Timezone 확인 |
| 2분마다 알림이 계속 옴 | 테스트로 바꾼 Schedule 을 되돌리고 **다시 Publish** (또는 ▾ → Unpublish) |
| `Referenced node doesn't exist` | `$('이름')` 안의 노드 이름이 바뀜 → 표현식 고치기 |
| 실행 횟수가 금방 줄어듦 | 체험판 1,000회 한도. Minutes 단위 Schedule 을 켜둔 워크플로우 찾아서 끄기 |

## 부록 C. 체험이 끝난 뒤 계속 쓰려면

1. 체험 종료 전: 모든 워크플로우 **Download** (종료 후에도 90일 안에는 다운로드 가능)
2. 내 컴퓨터에 Node.js 20.19~24 설치 → 터미널에서 `npx n8n` → `http://localhost:5678`
3. 새 워크플로우 → **⋯ → Import from File** → 받아둔 `.json`
4. 열쇠 다시 연결:
   - Telegram, Gemini → 토큰·키 그대로 붙여넣으면 끝
   - Google → 내 컴퓨터 n8n 은 "Sign in with Google" 간편 연결이 없어서 **Google Cloud 에서 OAuth 직접 설정** 필요 (교재 8단계 📦) → 어려우면 시트 대신 **Data table** 로 바꾸기
5. ⚠️ 내 컴퓨터 n8n 은 **컴퓨터와 터미널이 켜져 있을 때만** 돌고, **Telegram Trigger 는 공개 주소가 없어서 안 됩니다** (Schedule·Form·Chat 은 됨). 24시간 돌리려면 유료 Cloud 나 서버(Docker)
